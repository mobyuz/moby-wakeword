# Atribusiya (CC BY majburiyatlari)

Holat: qoralama. Quyidagi to'plamlar CC BY 4.0 ostida; litsenziya mualliflarni ko'rsatishni talab qiladi. Bu fayl nashr qilinadigan model relizi bilan birga yuboriladi (reliz izohiga ham ko'chiriladi). Litsenziyalar tekshiruvi: [licenses.md](licenses.md). Bu yuridik maslahat emas; model og'irliklari ma'lumotning "moslashuvi" hisoblanishi huquqiy jihatdan aniq emas, shuning uchun ehtiyot yo'li: mualliflarni baribir ko'rsatamiz.

Ma'lumot to'plamlari ularning nusxalari bilan birga tarqatilmaydi (klip'lar va generatsiya qilingan audio nashr qilinmaydi), faqat model nashr qilinadi.

Faqat shu to'plamdan haqiqatan foydalanilgan relizlarga tegishli yozuvlar relizga kiritiladi; qolganlari ishlatilmaguncha shu yerda "rejalashtirilgan" deb turadi.
